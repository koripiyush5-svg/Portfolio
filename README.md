# Piyush Kori — Satoru Gojo-Inspired Developer Portfolio ⚡

A premium, cinematic developer portfolio inspired by **Satoru Gojo** from *Jujutsu Kaisen*. Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌌 Features & Signature Visual Effects

1. **The Six Eyes Visual & Reveal**:
   - Concentric rotating radar rings with tick marks.
   - Core iris featuring a multi-layered cyan-to-violet radial gradient and electric glow.
   - Floating aura particles with randomized drift vectors and pulsing animations.
   - Hexagonal sacred geometry overlays evoking the Six Eyes.
   - Mobile-adaptive responsive layout.

2. **Limitless Cursor Aura**:
   - Fluid glowing blue energy halo that tracks the cursor on desktop devices (`(hover: hover)`).
   - Automatically disabled on touchscreens and respects accessibility `prefers-reduced-motion` settings.

3. **Infinity Particle Field**:
   - High-performance, lightweight background with 50 CSS-animated drifting particles.
   - Atmospheric energy orbs with slow breathing pulses.
   - Subtle geometric grid background.

4. **Domain Expansion Transitions**:
   - Cinematic radial energy wash that expands outwards as you scroll into the **Projects** and **Achievements** domains.
   - Infinite Void starfield background pattern with glittering starlight nodes.

5. **Cursed Techniques Project Showcase**:
   - Large interactive cards for:
     - **Blue**: *AI-Powered Intelligent Surveillance* (dynamic multi-camera tracking, risk scoring, real-time alerts).
     - **Limitless**: *Real-World Problem Solver*.
     - **Infinite Void**: *Open Source Contributions*.
   - Live demo and GitHub action buttons.

6. **The Six Eyes Skills Domain**:
   - Interconnected energy network connecting 6 fundamental learning nodes:
     - Python
     - HTML & CSS
     - JavaScript
     - Git & GitHub
     - Terminal & Linux
     - Problem Solving
   - Interactive hover glows, animated borders, and animated SVG power conduits.

7. **Domain Expansion Achievements**:
   - Vertical radiant timeline with glowing energy nodes.
   - Featured College Buildathon win during week 1, hackathons, open-source milestones, certifications, and goals.

8. **"The Grind Never Ends" Progression System**:
   - Anime-inspired level-up system showcasing continuous learning progress across 5 skill tracks with scroll-triggered animated stat bars.

9. **"Ready to Enter My Domain?" Contact & Footer**:
   - Direct glass action buttons for GitHub, LinkedIn, and Email.
   - Minimal signature footer: *"Designed with curiosity. Built with code. Inspired by the Limitless."*

## 🚀 Getting Started

### 1. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```

## 🛠️ Personalizing Placeholders

You can easily customize your links and content:

- **Contact Links**: Open [`src/components/Contact.tsx`](file:///Users/piyushhere/portfolio/src/components/Contact.tsx#L5-L21) and replace `YOUR_USERNAME` and `your.email@example.com` with your actual handles.
- **Projects & Demos**: Open [`src/components/Projects.tsx`](file:///Users/piyushhere/portfolio/src/components/Projects.tsx#L16-L53) to link your real GitHub repositories and live deployments.
- **Achievements & Dates**: Open [`src/components/Achievements.tsx`](file:///Users/piyushhere/portfolio/src/components/Achievements.tsx#L4-L45) to input your official event names, dates, and certificate links.
